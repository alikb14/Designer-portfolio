## Visual system

- Binary near-white/near-black themes with gray media placeholders.
- Monospaced/typewriter language; active navigation uses weight.
- Large canvas margins and negative space.
- Square corners; almost no decorative shadows/borders; pill theme switch is the exception.
- Work: two columns. Play: three. About: two.
- Project media provides nearly all color.

## Motion system

- Brief staggered particle/text entry reveal, not a long loader; the Earth resolves from scattered glyphs rather than scaling the whole layout.
- Global theme crossfade/inversion.
- Work inline motion previews.
- Play image-state change plus description reveal.
- Continuous Earth rotation is visible but remains secondary to the quick particle resolve.
- Requested pointer attraction/repulsion is new and needs prototype approval.

## Unknowns that must not be invented

- Mobile/tablet layouts and navigation.
- Contact body and form.
- Exact font/license and easing/durations.
- Audio, captions, controls, preview loop, and file limits.
- Whether Play description pushes layout or overlays it.
- CMS appearance/workflow.
